## Projects

Published under [Helx Systems](https://github.com/helx-systems).

**[StackHelx](https://github.com/TicoraX/StackHelx)** — local dev environment orchestrator, on PyPI.
One file at the project root and `shx up` brings up ports, Docker, backend and frontend. Ships an MCP
server so agents can start and inspect services. 474 tests run against real OS sockets, CI on

**[OrqueHelx](https://github.com/TicoraX/OrqueHelx)** — Hermes Agent plugin for delegating work

double-spend. Next.js, Electron, SQLite, Vitest.

**[OptiHelx](https://github.com/TicoraX/OptiHelx)** — Windows maintenance suite with dry-run mode on
every destructive action. Node.js, React, Electron.
